# Cineva VIP — persistent database version

This version uses PostgreSQL instead of local SQLite so KEY data can survive Render Free restarts/redeploys.

## Environment variables
- `DATABASE_URL` — PostgreSQL connection string from your free database provider (Supabase or Neon)
- `ADMIN_USER` — admin username
- `ADMIN_PASSWORD` — admin password
- `SESSION_SECRET` — random secret generated by Render

## Render
- Build Command: `npm install`
- Start Command: `npm start`
- Plan: Free
